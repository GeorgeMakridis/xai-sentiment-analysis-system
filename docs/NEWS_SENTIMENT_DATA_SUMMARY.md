# News Sentiment Data Summary

## Short Description

This dataset contains financial news articles with sentiment analysis covering **February 1, 2025 to April 15, 2025** (74 days). The data includes news articles from 99 different sources, covering 95 unique financial assets (stocks). Each article is associated with one or more stock symbols and includes sentiment scores calculated using FinBERT.
